# FinTrack: Personal Finance and Expense Tracker

A MongoDB (NoSQL) database project that tracks users, accounts, income, expenses and monthly budgets.

## Database
- Database: Feintrack
- Collections: Users, Accounts, Transactions, Budgets
- Platform: MongoDB Atlas (free M0 cluster)

## Files
- users.json, accounts.json, transactions.json, budgets.json: sample data
- queries.md: all queries with their purpose
- screenshots/: output screenshots

## Operations covered
Create, Read, Update, Delete, Aggregation ($match, $group, $sort), Join ($lookup)
